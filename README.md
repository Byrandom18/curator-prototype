# Прототип куратора проектного обучения

Статическая копия рабочих экранов partner.urfu.ru и TeamProject. Данные хранятся в браузере, сервер не нужен. Это подходит для GitHub Pages.

## Что можно проверить

1. На Партнёре открыть сводку: сколько проектов, сколько студентов нужно и сколько уже в группах.
2. Заполнить паспорт, отправить его партнёру и нажать «Партнёр подтвердил».
3. Продлить срок и добавить студентов в группу.
4. В TeamProject собрать итерацию из шаблона ролей и поправить текст задач.
5. Нажать «Напомнить тем, кто не сдал», переключиться на роль «Студент» и отметить сдачу.
6. Вернуться куратором и поставить балл. Отзыв студента остаётся в карточке итерации.

Кнопка «Сбросить демо» возвращает два исходных проекта.

## Локально

Откройте `index.html` в браузере или запустите из этой папки:

```
python -m http.server 8080
```

Адрес: `http://127.0.0.1:8080`
